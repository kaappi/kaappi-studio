# Developer Documentation

Contributor-focused documentation for Kaappi Studio, a Kotlin Multiplatform (KMP) app
for learning the Scheme programming language on iOS and Android.

## The 60-second version

- **`:shared`** — Kotlin Multiplatform module: domain models (`Example`, `SchemeFile`, `RunResult`, `ThemeMode`) and `expect`/`actual` repositories for files (per-app `schemes/` directory) and settings (SharedPreferences / NSUserDefaults).
- **`:app`** — Android app: Jetpack Compose UI + Material 3. A WebView hosts the CodeMirror 6 editor; Scheme code runs **natively** via [Chicory](https://github.com/dylibso/chicory), a pure-JVM WebAssembly runtime.
- **`iosApp/`** — SwiftUI app (project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`). The same WebView editor runs here, but Scheme code runs **inside the WebView** via the browser's WebAssembly runtime and a WASI shim.
- **`kaappi.wasm`** — the Kaappi Scheme interpreter compiled to `wasm32-wasi`, fetched from the [kaappi/kaappi](https://github.com/kaappi/kaappi) releases. It is **not committed** (gitignored) — see [Getting Started](getting-started.md#wasm-binary-required).
- The two halves talk over a small JSON message bridge; the protocol is documented in [Bridge Protocol](bridge-protocol.md).

## Where things live

| Path | Contents |
|------|----------|
| `app/src/main/java/com/kaappi/studio/` | Android UI (Compose), ViewModels, WebView bridge, Chicory `SchemeRunner` |
| `app/src/main/assets/webview/` | WebView assets shipped by the Android app (`index.html`, `bridge.js`, `editor.js`, …) |
| `shared/src/commonMain/` | Platform-independent domain models and repository interfaces |
| `shared/src/androidMain/`, `shared/src/iosMain/` | `actual` repository implementations |
| `iosApp/KaappiStudio/` | SwiftUI views, ViewModels, `SchemeWebView` bridge |
| `iosApp/KaappiStudio/Resources/webview/` | WebView assets bundled in the iOS app |
| `scripts/fetch-wasm.sh` | Downloads `kaappi.wasm` from Kaappi releases |
| `.cursor/skills/` | Automated release workflows (used by AI agents; see [Release Process](release.md)) |
| `.github/workflows/` | Android and iOS CI pipelines |
